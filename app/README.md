# Application (Flutter)

The cross-platform mobile application — one Flutter codebase building to both iOS
and Android. It renders the three role-based experiences (coach, athlete, parent)
described in `../Scaffolding/Planning_and_Ideation/Primary_User_Flows.md`, talks
to the backend over HTTPS, and receives push notifications via Firebase Cloud
Messaging.

## Layout

This skeleton is organised **feature-first**: everything for one user-facing area
lives together rather than being split across layer folders.

```
lib/
├── main.dart            Application entrypoint (generated by `flutter create`)
├── features/
│   ├── authentication/  Login (email / username / password)
│   ├── calendar/        Green / amber / red day grid and flip-card detail
│   ├── sessions/        "Upcoming Sessions" list, commitments, who is going
│   └── notifications/   In-app notification handling
├── models/              Plain Dart data classes (Session, Commitment, …)
├── services/            Backend API client, push messaging, local storage
└── shared/             Shared widgets, theme, the rating colours
test/                    Widget and unit tests
```

## Not generated yet

`main.dart`, `pubspec.yaml`, and the `android/` and `ios/` platform folders are
produced by running `flutter create` in this directory. That step is deliberately
left until we start building the application, so this skeleton stays free of
generated noise.
